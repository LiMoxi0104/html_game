# 永恒回归 · 权能轮回

一个关于「权力异化与自我觉醒」的循环叙事网页游戏。纯静态单文件实现（HTML + CSS + JS，零依赖）。

## 核心循环
继承者 → 击败领主 → 成为领主 → 被新继承者击败 → 继承者（下周目）
唯一真结局：**觉醒值 ≥ 5 时，领主可选择「自我放逐」——长按空格（或触屏）3 秒打碎权能，终结循环。**

## 玩法
- **继承者阶段（卡牌战斗）**：10 节点卷轴推进。遭遇兵种用回合制卡牌战斗（15 种技能，含 MP / 冷却 / 抽补牌），遭遇防御塔立即触发陷阱效果，空节点触发事件或休整。
- **领主阶段（塔防布置）**：10×3 棋盘放置兵种与防御塔（消耗布置点数）。布置完成后继承者自动进攻，棋盘模拟自动战斗。守成者会在侧栏提出极端建议（拒绝 +1 觉醒，最多 3 次），亦可「查看记忆碎片」+1 觉醒。
- **阶段 C 对峙**：继承者抵达王座，进入卡牌战斗。领主胜则循环继续（继承者更强），败则玩家转为继承者。
- **真结局**：当玩家为领主且觉醒 ≥ 5，对峙画面出现【自我放逐】，长按空格 3 秒触发白屏湮灭，清空存档。

## 运行
直接双击 `index.html` 即可在浏览器游玩（数据存于 `localStorage` 键 `eternalReturnSave`）。

## 部署（Cloud Studio / 任意静态托管）
将 `index.html` 单文件上传至任意静态网站托管即可。本项目已包含 `server.js`（极简静态服务器）用于本地预览：
```
node server.js   # 然后访问 http://localhost:5173
```
也可直接上传 `index.html` 到 GitHub Pages / Netlify / Cloud Studio 静态托管，无需构建。

## 与文档的取舍说明
- 真结局按文档「清空存档」执行；为保留「英灵殿」雕像记录，雕像（gallery）单独保留，仅清除循环进度。
- 领主阶段 C 中，玩家（领主）使用全部 15 张技能作为「强化版权能」。
- 继承者阶段空节点以「事件/休整」呈现，记忆碎片叙事融入领主阶段「查看记忆碎片」。
